# Agent Instructions

This repository follows the project-handoff workflow.

Before starting substantial work, read:

- README.md
- docs/PROJECT_CONTEXT.md
- docs/CURRENT_STATUS.md
- docs/DECISIONS.md
- docs/TASKS.md

Also inspect:

- git status
- current branch
- recent git log
- relevant diffs

## Working rules

Use Git as the authoritative history of implementation.

Do not allow important project knowledge to exist only in the conversation.

Before major work:
1. Understand the current task.
2. Understand the acceptance criteria.
3. Check existing architectural decisions.
4. Work on an appropriate task branch.

After meaningful work:
1. Run relevant tests.
2. Update docs/CURRENT_STATUS.md.
3. Update docs/TASKS.md.
4. Update docs/DECISIONS.md if a new important decision was made.
5. Review git diff.
6. Commit meaningful completed work.

Before switching model, provider, CLI, machine, or handing work to ChatGPT,
perform a project handoff checkpoint.
